# Hi, I'm An

I'm a full-stack AI engineer in Hanoi. I build LLM agents, RAG systems, document AI and voice assistants, together with the backend, frontend and cloud setup they run on.

## Selected projects

- [ViPharmind](https://github.com/doanan293/ViPharmind): an agentic RAG assistant for Vietnamese drug information. Hybrid retrieval with a reranker reaches Hit@10 97.7%, and the agent hallucinates 18 times less than the model on its own. Published at SoICT 2026. [Live demo](https://vipharmind.vercel.app)
- [ViLearnest](https://github.com/doanan293/ViLearnest): a full-stack learning platform with Stripe payments, built on Next.js, Fastify and PostgreSQL. [Live demo](https://vilearnest.vercel.app)
- [WebCorpusPipeline](https://github.com/doanan293/WebCorpusPipeline): a crawling and document parsing pipeline that turned 92k web pages and 3k files into a versioned corpus of 80k articles.
- [SpeechTextNormalizer](https://github.com/doanan293/SpeechTextNormalizer): a library that rewrites Vietnamese numbers, dates and units as spoken words before text-to-speech.
- [StockSentimentAdvisor](https://github.com/doanan293/StockSentimentAdvisor): stock recommendations from news, prices and financial ratios, published at ICISN.

Most of my production work lives in private repositories: document extraction for courts and banks (48 document types, 22,000 pages a day), a voice reporting assistant for airline cabin crew, a text-to-SQL analytics assistant, and an MCP-based accounting assistant used by 10,000 organizations.
